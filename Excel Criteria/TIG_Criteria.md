# TIG Criteria

## Core Requirements

| Requirement | Detail |
|-------------|--------|
| Minimum Debt Level | £6,000 |
| Minimum Disposable Income | £100 on all cases |
| Financial Statement | Must be within SFS guidelines |
| DLA/PIP | Must always be offset |

---

## Income

- We require **1 full month wage slip** for each wage on the I&E (including partners where applicable). This should be dated in the **last 3 months**.
  - Unless not available for exceptional circumstances — Portal or similar can be used with manager's sign-off.
- Ensure **Tax Code is correct**.
- We require **benefit letters** from the current financial year, or shown on a recent bank statement in the current financial year.
- **Universal Credit** — need full journal dated in the last 3 months.
- **Self Employed** = Tax Return / 3 months banking.
- **If newly self employed** — needs to be a minimum of 3 months in the job, and confirmation of hours/pay etc.
- **CIS** — minimum of 1 month's invoice showing 20% deduction.

---

## Bank Statements

- Bank statement needs to be dated within the **last 3 months** — 1 full month for every account (including savings).
- Needs to be **clear who the account belongs to**.
- **Gambling MUST BE under £1,000** along with GAMSTOP if over £200.
- Any DDs/SOs/regular transactions will need to be explained if they are either not on the I&E or the amounts are different.

---

## Proof of Debts

We require proof of all debts to verify all cases. This can be any combination of:

- **Debts under £1,000** can be verbal if not able to get a POD (unless it's a debt level issue).
- **Credit Report** — if the client has Shop Direct, we require a credit report that shows granular details of the recent spending.
- **Creditor Letters** — dated within last 6 weeks, including reference numbers.
- **Debt Collector Letters** — dated within the last 6 weeks, with original creditor information visible including reference numbers and names of original creditors.
- **3-Way Calls** with Debt Collectors or creditors (including reference number and full account balance including interest) — the actual time in the call when the information is discussed will help the case progress quickly.
- **CCJs** — need details of original creditor if client doesn't know.
- **All 3rd party letters** need to be signed and dated with the address of the 3rd party along with either a mobile number or email address.
  - Any third-party contributions — state how long it will last.
- **Previous IVA** — if client has been on a previous IVA, we need to know when and why it failed along with what's changed since the previous proposal (DI/Debt Level). **NEED TERMINATION REPORT.**

---

## HMRC Rules

| Rule | Detail |
|------|--------|
| HMRC Majority | MUST NOT have a deduction from income or benefits — **will reject** |
| HMRC Majority | WILL REJECT if previous IVA or Bankruptcy |
| HMRC Self Assessment | If still self-employed, will vote to reject if any late submissions — must have submitted and HMRC confirm received |
| HMRC Equity | WILL REJECT if more equity than their debt |
| HMRC Bankruptcy Return | WILL REJECT if return higher in bankruptcy |
| HMRC Full & Final | Won't accept full and final from savings if client only has savings from avoiding paying debts |
| SEISS Fraud | Recovery of incorrectly claimed self-employed income support scheme (SEISS) **CANNOT BE INCLUDED — FRAUD** |
| Joint Debts | Where a debt is joint and only one party is entering into an IVA, HMRC will remove the client's name from the account and chase the second party |
| Minimum Debt Threshold | WILL NOT VOTE on debts lower than £4,000 unless they are rejecting |
| Benefits Only | WILL REJECT if benefits only |

---

## General Rejection / Watch Flags

- **Equity Exceeds Liabilities** — greater return in Bankruptcy (only for NON WPM or Eversheds cases). Reason needed for why they aren't remortgaging to repay debts.
- **Council Majority** — MUST NOT have a deduction from income or benefits (will reject). **Case by case — check council list.**
- **Recent Spend** — equivalent of monthly salary in last 2 months. EG: £1,000 income = £500 each month for last 2 months (excluding payday loans). *(WATCH)*

---

## Creditor-Specific Rules

### Shop Direct
- So long as not spent in last 3 months (statement date) or 4 months of order.
- **Account Age**: must be at least 6 months old.

### Creation (Sygma / Laser)
- So long as not spent in last 3 months (statement date) or 4 months of order.
- **PLEASE DO NOT RUN ANY FURTHER TRIALS ON RECENT SPEND WITH SYGMA / CREATION / LASER REGARDLESS OF THE REASON.**

### Link
- **Mid SFS guidelines ONLY** must be used.
- **£12,000 minimum debt level.**
- REJECT if equity is more than their debt.
- REJECT if benefits are more than 10% of household income.
- REJECT if previous IVA failed due to arrears.
